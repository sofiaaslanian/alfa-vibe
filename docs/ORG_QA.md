# Ответы оргкомитета (чат) — выжимка для команды

Источник: переписка с организаторами хакатона. Не ТЗ, а уточнения.

## Маскирование и оценка

- Составные значения (серия/номер паспорта, части адреса): при любом методе скрытия задача — чтобы **нельзя было восстановить** данные при утечке.
- Лишние маски штрафуются **слабее**, чем пропуски.
- Эталона маски **нет**. Сравнивают качество относительно оригинала (span-based). Формат маски любой (`*`, `[PERSON_1]`, …).
- Частично открытые символы (45 56, i*@mail.ru, инициалы) — оценка **чуть ниже**, чем полное скрытие.
- Разделители (точки, дефисы, пробелы) — на ваше усмотрение.
- Длина маски vs оригинал — **не влияет**.
- Весь payload = одно значение, полное скрытие строки — **не** избыточность.
- Замаскировать служебные слова («серия», «ул.») вместе со значением — **штраф** как избыточность.
- 17 категорий: отдельные слова и фразы/предложения.

## Нагрузка и SLA

- Прогон автоматизирован при отправке (или ручной запуск жюри). Участникам система недоступна; до оценки прогонят последние версии.
- Разгон нагрузки: средний RPS ~**330**, пики до **1000**.
- **429 + Retry-After не ошибка SLA**, но в статистике.
- Latency: смотрят среднее, p50, p95, p99.
- Число demask ≈ числу mask; на demask всегда приходит **ваша** маска без правок LLM.
- Параллельность до **200** sync-коннектов (ожидают ответ mask).
- 1000 RPS = любые HTTP к сервису; размеры текстов разные; 100k токенов — отдельно/в смеси.
- Ориентир latency — **ТЗ** (артефакт 0.5 с в критериях). Меряют только ваш сервис, не LLM.

## /process и auth

- `payload_id` уникален на пару mask↔demask; повтор только при ошибке/429.
- TTL state — на ваше усмотрение.
- API-ключ / X-System на автопроверку **/process не обязательны** (баллы за отсутствие auth не снимут).

## Что учли в коде после Q&A

- `/process` **без** API-ключа (auth только `/proxy` + `/demo`).
- Неизвестный `X-System` на `/process` игнорируется (не 403).
- Без `X-System` → NER **выключен** (RPS).
- Перегрузка → **429 + Retry-After: 1** (`PROCESS_CONCURRENCY`, default 180).
- Паспорт/ВУ: серия и номер — **отдельные** spans, слово «номер» не маскируется.
- `REDACTED_SPAN` не отфильтровывается; ALLOW не сливается в mask-union.
- `docker-compose.yml` починен (сломанный YAML у redis).

## Сознательно не трогали

- ADDRESS пока целиком (`ул.`/`д.` внутри span). Лишние маски штрафуют **слабее** пропусков; вырезать лейблы рискованнее для recall. Можно допилить после RU-цифр.
