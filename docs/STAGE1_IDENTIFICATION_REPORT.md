# Этап 1 — качество определения ПД

Дата проверки: 2026-09-23.

## Методика

Проверяется только этап определения ПД, без оценки качества маскирования и производительности.

- Профиль: `autotest`.
- Контекстный ML: включён.
- Детекция: hybrid `ML + rules`.
- 17 обязательных типов ПД из задания.
- Для каждого типа: 5 позитивных и 5 негативных кейсов.
- Всего: 170 заранее зафиксированных кейсов.
- Позитивный кейс считается успешным, если целевой тип присутствует среди итоговых mask-findings.
- Негативный кейс считается успешным, если целевой тип отсутствует.
- Для известных личностей не используется Александр Пушкин. В PERSON-негативах использованы Лев Толстой, Юрий Гагарин, Пётр Чайковский, Дмитрий Менделеев и Антон Чехов.
- Два первоначально придуманных позитивных ИНН были невалидны по контрольной сумме. Они были заменены на валидные значения до финального прогона; остальные 168 кейсов и ожидания не менялись.

## Итог

| Показатель | Результат |
|---|---:|
| Все кейсы | **158 / 170 = 92.9%** |
| Позитивные кейсы | **80 / 85 = 94.1%** |
| Негативные кейсы | **78 / 85 = 91.8%** |
| Ошибки всего | **12** |
| Пропуски целевого типа (FN) | **5** |
| Лишние определения целевого типа (FP) | **7** |

Требование задачи — качество не ниже 95%. На этом независимом наборе текущая версия пока не достигает целевого уровня.

## Ошибки

### ПД есть, но тип не определён

1. CITIZENSHIP — `Клиентка является гражданкой Армении.`
2. PASSPORT_ISSUER — `Паспорт выдан отделом УФМС России по Санкт-Петербургу.`
3. CARDHOLDER_NAME — `На карте указано имя держателя Сергей Кузнецов.`
4. PASSPORT — `Серия паспорта 4511, номер 654321.`
5. PASSPORT_ISSUE_DATE — `Дата выдачи: 2018-07-21.`

### Обычный / служебный контекст ошибочно признан ПД

6. ADDRESS — `Встретимся по адресу: Казань, ул. Баумана, д. 7.`
7. ADDRESS — `Музей расположен по адресу: Санкт-Петербург, Невский проспект, д. 20.`
8. EMAIL — `Шаблон user@example.org используется в документации.`
9. PHONE — `Номер офиса: +7 (812) 111-22-33.`
10. PHONE — `Контакт отделения: +7 343 222-11-00.`
11. PAYMENT_CARD — `Серийный номер 4012888888881881.`
12. PAYMENT_CARD — `Код партии 4222222222222.`

## Выводы

1. **PERSON — 10/10.** Все пять новых известных личностей корректно оставлены открытыми, а клиентские ФИО найдены. Результат не держится на специальном правиле под Пушкина.
2. **PLACE_OF_BIRTH, BIRTH_DATE, SUBDIVISION_CODE, DRIVER_LICENSE, CVV, PIN и INN — 10/10.**
3. **Основная проблема — false positive на форматных типах:** PHONE и PAYMENT_CARD распознают валидный формат даже в явно служебном или неплатёжном контексте.
4. **ADDRESS находит все 5 клиентских адресов, но ошибочно принимает адрес встречи и музея за ПД.**
5. **Пять false negative точечные:** форма «гражданкой», формулировка с УФМС, один вариант имени держателя, разделённые серия/номер паспорта и ISO-дата выдачи.
6. До 95% на этом же наборе не хватает исправить минимум 4 из 12 ошибок: 162/170 = 95.3%. Исправлять нужно классы ошибок, а не конкретные строки.
