# Зафиксированные решения

Только то, что видно в коде, комментариях или сообщениях коммитов.

- `POST /process` не проверяет API-ключ. Комментарий в `app/api.py`: автотест организаторов ключ не присылает. `/proxy/chat` ключ проверяет.
- Нет заголовка `X-System` на `/process` — система `autotest`. Комментарий в `app/process.py`.
- Профиль `autotest` имеет `use_context_ml: false`. Комментарий в `config.yaml`: так держат задержку AlfaSonar; ML остаётся у `demo`. Коммит `4052faf`.
- Две маски. `dev_redact_v1` заменяет буквы и цифры на `*`. Scoped token вида `⟦PII_TYPE_hex⟧` используется proxy. Код: `app/masking.py`. Для `demo` в конфиге указан `scoped_token`, для `autotest` и `high_rps` — `dev_redact`.
- Состояние общее для воркеров и пишется атомарно. При Redis значение шифруется, ключ операции — HMAC. Код: `app/state.py`, `app/crypto_util.py`.
- Повтор того же текста может взять уже посчитанную маску из кэша Redis и из словаря процесса. Коммит `4052faf`, код `app/process.py`.
- Перегруз `/process` отвечает `429`, а не копится в очереди. Семафор `PROCESS_CONCURRENCY`, по умолчанию в Compose `2`. Коммит `4052faf`.
- Чужой текст на занятом `payload_id` даёт `409`. Истёкшая запись даёт `410`. Код `app/process.py`. Причина именно этих кодов в ТЗ не расписана; в README они названы контрактом state.
- NER вынесен в отдельный образ без установки torch в API-образ. Комментарий в `docker-compose.yml`.
- Если context ML включён и sidecar падает, детектор может закрыться ошибкой (`CONTEXT_ML_FAIL_CLOSED` по умолчанию `1`) и `/process` ответит `503`. Код: `app/pii/detect.py`, `app/api.py`. На профиле `autotest` этот путь сейчас не используется.
- PIN и CVV на системе `demo` маскируются только вместе с картой: `combo_require` в `config.yaml`.
- Бонусные типы СНИЛС, загранпаспорт и ОМС в комментарии `config.yaml` вынесены из ядра оценщика. Функции детекции в `app/pii/rules.py` при этом остались.
- Образы API и NER переключаются на пользователя `app`. Коммит `e79f468`.

Причина, почему публичный стенд обслуживается через `docker-compose.http.yml`, а не через Caddy: в файле написано «временный публичный HTTP без домена». Другого обоснования в git-сообщении нет.
